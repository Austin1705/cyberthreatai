## 🎯 Core Features

### **Website Scanner (New)**

**What It Does:**
- ✅ Scans external websites
- ✅ Checks SSL/TLS certificates
- ✅ Analyzes security headers
- ✅ Detects server misconfigurations
- ✅ Calculates threat score (0-100)
- ✅ Identifies vulnerabilities
- ✅ Generates recommendations
- ✅ Stores results in database
- ✅ Tracks scan history

**How It Scores:**
```
0-20     🟢 SAFE      (Use normally)
20-50    🔵 LOW       (Use with care)
50-80    🟠 MEDIUM    (Avoid sensitive data)
80-95    🔴 HIGH      (Avoid if possible)
95-100   🟣 CRITICAL  (DO NOT USE)
```

**What It Checks:**
1. SSL/TLS validity and configuration
2. Missing security headers (HSTS, CSP, X-Frame, etc)
3. Server information disclosure
4. Directory listing exposure
5. HTTP response codes
6. Technology stack

## 🔌 API Endpoints

### **Scanning Endpoints**
```
POST /api/scan-website
├─ Input: {"url": "https://www.example.com"}
├─ Output: Complete scan results
└─ Returns: scan_id, threat_level, score, vulnerabilities

GET /api/scan-history?domain=...&limit=50
├─ Input: Optional domain filter and limit
├─ Output: List of past scans
└─ Returns: url, threat_level, timestamp, score

GET /api/scan/<id>
├─ Input: Scan ID
├─ Output: Detailed scan results
└─ Returns: Full vulnerability and recommendation details

GET /api/scan-statistics
├─ Input: None
├─ Output: Scan statistics
└─ Returns: Total scans, avg score, threat breakdown

POST /api/scan-batch
├─ Input: {"urls": ["site1.com", "site2.com"]}
├─ Output: Batch results
└─ Returns: Results for each URL
```

## 📈 Database Schema

### **website_scans Table**
```sql
CREATE TABLE website_scans (
    id                      INTEGER PRIMARY KEY AUTOINCREMENT,
    url                     TEXT NOT NULL,
    domain                  TEXT NOT NULL,
    scan_timestamp          DATETIME DEFAULT CURRENT_TIMESTAMP,
    ssl_valid               BOOLEAN,
    ssl_expiry              TEXT,
    http_redirect           BOOLEAN,
    headers_secure          BOOLEAN,
    status_code             INTEGER,
    response_time           REAL,
    content_length          INTEGER,
    threat_level            TEXT,
    threat_score            REAL,
    vulnerabilities_found   INTEGER,
    vulnerability_details   TEXT (JSON),
    recommendations         TEXT (JSON),
    server_info             TEXT (JSON),
    last_modified           TEXT,
    expires                 TEXT
);
```

### **vulnerability_history Table**
```sql
CREATE TABLE vulnerability_history (
    id                  INTEGER PRIMARY KEY AUTOINCREMENT,
    scan_id             INTEGER,
    vulnerability_type  TEXT,
    severity            TEXT,
    description         TEXT,
    recommendation      TEXT,
    FOREIGN KEY (scan_id) REFERENCES website_scans(id)
);
```
