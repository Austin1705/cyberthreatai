⚙️ SETUP (First Time)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. 📧 Go to Email Config tab
  2. 🔑 Get App Password from Gmail:
     → https://myaccount.google.com/apppasswords
  3. ⚙️ Fill in settings:
     SMTP: smtp.gmail.com
     Port: 587
     Email: your-email@gmail.com
     Password: 16-char App Password
  4. 💾 Click "Save Configuration"
  5. ✅ Click "Test Email"

📋 SEND REPORT (When vulnerabilities found)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Go to: /reports.html → "Send Alert" tab (second form)

  1. Enter URL
  2. Paste JSON vulnerabilities:
     [{
       "type": "SQL Injection",
       "severity": "CRITICAL",
       "description": "...",
       "recommendation": "..."
     }]
  3. Click: Send Report
  4. ✉️ Detailed report emailed

❓ QUICK TROUBLESHOOT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Email not sending?
  → Check Gmail App Password (not regular password)
  → Ensure 2FA is enabled
  → Try clicking "Test Email" button

  API not found?
  → Check if API server is running (port 5001)
  → Check server console for errors

  Reports not saving?
  → Check if "reports/" directory exists
  → Check file permissions
  → Check available disk space

  Can't access dashboard?
  → Check frontend server is running (port 8000)
  → Try http://localhost:8000/reports.html
  → Check browser console for errors

🎯 COMMON WORKFLOWS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Workflow 1: Manual Alert
  ───────────────────────────
  1. Website goes down
  2. Go to /reports.html
  3. Click "Send Alert"
  4. Enter URL + error
  5. Click send
  6. Email received in 30 seconds

  Workflow 2: Auto Alert from Code
  ────────────────────────────────
  1. Integrate in your monitoring script
  2. Call API endpoint /api/report/send-alert
  3. Email sent automatically when triggered
  4. Reports visible in dashboard

  Workflow 3: Compliance Report
  ────────────────────────────
  1. Run security scan
  2. Get list of vulnerabilities
  3. Send via /api/report/vulnerability
  4. Email sent with severity breakdown
  5. Download JSON for compliance
