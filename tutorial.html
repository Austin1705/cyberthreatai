📊 Understanding Results

Normal Traffic (Safe):

{ "is_malicious": false, "threat_type": "Normal", "confidence": 1.0, "malicious_probability": 0.0 }

✓ Green Badge = Safe Traffic

Malicious Traffic (Threat):

{ "is_malicious": true, "threat_type": "Malicious", "confidence": 1.0, "malicious_probability": 1.0 }

⚠️ Red Badge = Threat Detected!

🔍 The 10 Network Features Analyzed

Feature What It Measures Normal vs Malicious
packet_size Size of data packets (bytes) Normal: 256 | Malicious: 512
packet_rate Packets sent per second Normal: 10 | Malicious: 95
protocol_tcp Using TCP protocol (0 or 1) Normal: 1 | Malicious: 1
protocol_udp Using UDP protocol (0 or 1) Normal: 0 | Malicious: 1
protocol_icmp Using ICMP protocol (0 or 1) Normal: 0 | Malicious: 1
src_port_common Source port is common (0 or 1) Normal: 1 | Malicious: 0
dst_port_common Destination port is common (0 or 1) Normal: 1 | Malicious: 0
connection_duration How long connection lasts (sec) Normal: 45 | Malicious: 3
payload_entropy Data randomness (higher = suspicious) Normal: 4.2 | Malicious: 6.8
retransmission_rate Percentage of retransmitted packets Normal: 0.01 | Malicious: 0.35
